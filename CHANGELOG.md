# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2025-01-01

### Added

- Initial release of AI Agents Academy
- Home page with hero section, features overview, and interactive demo
- 5 learning paths: Beginner, Intermediate, Advanced, Industry, Research
- 18+ lessons covering AI fundamentals through advanced agent topics
- Interactive AI Agent Playground with simulated execution
- Visual simulations for RAG, ReAct, Tool Calling, and Multi-Agent workflows
- Quiz and exam system with MCQ, true/false, and scenario questions
- Hands-on project guides for building real AI agents
- Full English and Arabic language support with RTL layout
- Light and dark theme with system preference detection
- Progress tracking with local storage persistence
- Responsive design for desktop, tablet, and mobile
- GitHub-ready project structure with CI/CD
- Comprehensive documentation
